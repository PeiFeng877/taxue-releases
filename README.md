# taxue-releases

Public **Sparkle** appcasts and release zips for **踏雪 (Taxue)** — a personal macOS screenshot tool.

- App source (not published here): local fork of [ciro-maciel/screenshots](https://github.com/ciro-maciel/screenshots) (MIT).
- Bundle id: `com.abi.taxue`
- Feed: [appcast.xml](https://github.com/PeiFeng877/taxue-releases/releases/latest/download/appcast.xml) on the latest GitHub Release

This repository stores **release artifacts only** (zip / appcast / deltas). It is not the application source tree.
